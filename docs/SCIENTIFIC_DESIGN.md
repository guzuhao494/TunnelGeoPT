# 科学设计

## 1. 最小科学问题

在未见隧洞断面、原岩应力方向和岩体非均质条件下，廉价的岩石应力提升预训练能否减少预测应力、损伤热点和裂纹拓扑所需的高保真破裂仿真案例？

当前仓库只是这个问题的数据与验证底座，不声称已经学会岩爆机制。

## 2. 假设

- **H0（零假设）**：在严格的case-level OOD划分下，Stress-Lift预训练相对从零训练、静态几何预训练和随机lift预训练，不提高性能—数据量曲线。
- **H1（备择假设）**：Stress-Lift在相同高保真案例数下提高OOD性能，或者在相同误差下减少至少20%的高保真案例。

20%是预注册的继续投入门槛，不是由当前代码计算出的结果。

## 3. 三层数据证据

### A层：几何—边界先验

- 输入：闭合隧洞空腔、围岩查询点、洞壁点、动力提示。
- 输出：多个离散位置到最近洞壁的向量距离。
- 物理范围：边界输运和几何相关性。
- 明确缺失：动量平衡、本构、损伤、断裂、接触、耗散和速率效应。

### B层：低成本力学监督

- 圆洞解析解用于单元测试和符号/量纲锚定。
- 二维线弹性FEM扩展到马蹄形、直墙拱形、粗糙洞壁和分步卸荷。
- 标签包括位移、六分量应力或二维等价分量、应变能和物理残差。

### C层：高保真破裂监督

- FDEM/DEM/相场生成损伤、裂纹、断裂耗散能、动能和源事件。
- 首版保存AE源目录，不合成传感器波形。
- 选取小子集跨求解器复算，以估计solver bias。

## 4. 参数化原则

优先保存原始量和下列无量纲量：

- `x/R`
- `sigma/UCS`
- `E/UCS`
- `f_t/UCS`
- `G_c/(UCS*R)`
- `joint_spacing/R`
- `support_pressure/sigma_1`
- `excavation_advance/R`

材料参数按岩性参数组联合采样，不将弹性模量、强度、断裂能和摩擦参数完全独立随机化。每个案例保留随机种子、求解器版本、输入哈希、网格尺度、收敛状态和单位约定。

## 5. 尺度策略

全隧洞模型不显式解析所有矿物颗粒。微细观数据用于学习可解释的桥变量，例如刚度退化、损伤张量、断裂能、断裂过程区尺度和源事件统计；隧洞尺度用随机场、显式节理/DFN及尺寸效应参数承接这些桥变量。

## 6. 模型顺序

1. Transolver或同级神经算子预测单个开挖阶段的场量；
2. 验证预训练是否确实节省高保真标签；
3. 再加入分步卸荷的状态转移；
4. 最后研究快速破裂—弹射的时序世界模型和现场观测头。

不把稳态场预测包装成时序世界模型。

## 7. 评价量

- 连续场：relative L2、峰值误差、平衡残差、边界牵引误差；
- 损伤热点：PR-AUC、IoU、热点质心位置误差；
- 裂纹：成核时间/位置、连通性、分支数、拓扑距离；
- 能量：弹性能、断裂耗散能、动能的误差和能量平衡；
- 不确定性：校准误差和覆盖率；
- 核心横轴：独立高保真案例数，而不是网格点数或时间帧数。

## 8. 停止条件

满足任一条件时停止扩充A层数据并重新审查路线：

- 随机lift、Stress-Lift和静态预训练在OOD数据效率上无稳定差异；
- 打乱应力方向或边界条件后性能不下降，说明模型没有使用物理提示；
- 误差随网格、洞径或断裂过程区/洞径比系统漂移；
- 物理残差和能量误差随预测指标改善而恶化；
- 高保真求解器之间的偏差大于模型方法之间的差异。
