# Experiment records

This directory stores durable run contracts and summaries. The initial
`smoke-v0.1.0` run validates executable paths, array schemas, determinism and
analytical invariants only. It is an auxiliary/development run, not evidence
for the Stress-Lift research hypothesis.

Future main runs must record the exact commit, configuration, case-level split,
seeds, command, environment, output paths, metrics and baseline comparison.
